# Enable upload on save

Turn on automatic uploads so every save mirrors to the remote.

Run **SFTP: Toggle Upload on Save** to flip `uploadOnSave` in your `sftp.json`
without hand-editing it — the status-bar item shows a `$(cloud-upload)`
indicator and an "Upload on Save: On/Off" tooltip reflecting the current state.

With it on, saving a file uploads it automatically. You're all set — edit
locally and your changes flow to the server on every save.
