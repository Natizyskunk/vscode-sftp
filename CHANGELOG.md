# Changelog

## [Unreleased] — 2026-03-04

### 🆕 Новые возможности

#### 🧠 Умная дельта-синхронизация (`smartSync`)

- Новая опция `syncOption.smartSync: true` — перед синхронизацией анализирует файлы по mtime/size
- Только изменённые файлы передаются (не все подряд!)
- Перед запуском открывается **Webview preview** с таблицей что будет загружено/скачано
- Настройка `conflictResolution`: `newer` / `local` / `remote` / `skip`
- Настройка `mtimeDeltaSeconds` для учёта clock drift FAT/NFS серверов

#### 📋 Transfer Queue Panel

- Команда **"SFTP: Открыть очередь передачи файлов"** — Webview с живым списком файлов в очереди
- Показывает: статус (⏳🔄✅❌), направление (↑↓), прогресс-бар, скорость в KB/s
- Кнопки: отменить всё, повторить ошибки, очистить завершённые

#### ⚙ Визуальный конфигуратор серверов

- Команда **"SFTP: Настроить сервер"** — GUI-форма вместо редактирования sftp.json вручную
- Поля: протокол (SFTP/FTP/FTPS), хост, порт, аутентификация, пути, синхронизация
- **Кнопка "Тест соединения"** прямо в форме

#### 🌍 Русификация

- Все **43+ команды** переведены на русский язык
- Меню VS Code отображает русские названия при установленной RU-локали
- Runtime-сообщения расширения локализованы через `vscode-nls`

#### 🔌 Стабильность соединений

- **Автоматические повторные попытки** при ECONNRESET, ETIMEDOUT, socket hang up
- **Пул соединений** — лимит параллельных подключений (по умолчанию 4)
- Новые параметры в `sftp.json`: `maxConnections`, `retryCount`, `retryDelay`

#### 🔍 Remote Explorer улучшения

- **SFTP: Изменить права доступа (chmod)** — диалог ввода прав 644/755/777 для удалённых файлов
- **SFTP: Поиск файлов на сервере** — живой QuickPick-поиск с рекурсивным обходом (дебаунс 400мс)

### 🛠 Технические улучшения

- Миграция с TSLint → **ESLint** (TSLint устарел)
- Удалён `tslint` из devDependencies
- Jest-трансформер обновлён для **Jest 28+** совместимости
- **CI/CD GitHub Actions** — автоматический lint + тест + сборка на Node 18/20
- `webpack.config.js`: `transpileOnly: true` — быстрее сборка
- **10 новых тестов** для deltaSync (computeDiff)
- **12 новых тестов** для connectionPool (isRetryableError, executeWithRetry)

### 🔧 Новые параметры `sftp.json`

```json
{
  "maxConnections": 4,
  "retryCount": 3,
  "retryDelay": 3000,
  "syncOption": {
    "smartSync": true,
    "conflictResolution": "newer",
    "mtimeDeltaSeconds": 2
  }
}
```
